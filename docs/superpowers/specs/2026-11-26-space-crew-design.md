# 스페이스 크루 — 설계

2026-11-26

## 무엇

협동 트릭테이킹. 전원이 같은 팀이고 같이 이기거나 같이 진다.
각자 "내가 이 카드를 따야 한다"는 임무를 받는데, 손패 얘기는 할 수 없다.

원작은 The Crew: The Quest for Planet Nine (Thomas Sing).

## 규칙과 창작물을 나눈 이유

규칙(트릭테이킹·통신 토큰·임무 판정)은 그대로 구현한다. 그건 이 게임이 어떤
게임인지를 결정하는 부분이다.

반면 원작의 미션 50개는 디자이너가 쓴 창작물이라 그대로 옮기지 않는다.
대신 원작이 난이도를 올릴 때 쓰는 레버 네 가지를 파라미터로 두고 사다리를 만든다.
웹게임 입장에서도 이쪽이 낫다 — 50개를 다 깨도 끝나지 않는다.

## 덱

40장.

| 종류 | 구성 |
|---|---|
| 색 카드 | 분홍·파랑·초록·노랑 × 1~9 = 36장 |
| 로켓 | 1~4 = 4장 (트럼프) |

## 인원과 분배

3~5인. 2인(JARVIS 변형)은 나중.

| 인원 | 분배 |
|---|---|
| 3인 | 14 / 13 / 13 — 14장 받은 사람의 마지막 1장은 쓰지 않는다 (트릭은 13번) |
| 4인 | 10장씩 |
| 5인 | 8장씩 |

**사령관** = 로켓 4를 받은 사람. 미션마다 다시 섞으므로 매번 바뀐다.
사령관이 임무를 먼저 고르고 첫 트릭을 리드한다.

## 트릭

- 선 카드의 색을 **반드시 따라간다**. 없으면 아무거나(로켓 포함)
- 로켓은 모든 색을 이긴다. 로켓끼리는 숫자가 큰 쪽
- 색끼리는 선 색 중 가장 높은 숫자가 이긴다. 선 색이 아닌 카드는 이길 수 없다
- 이긴 사람이 다음 트릭을 리드한다

## 임무와 승패

임무 카드는 색 카드와 1:1 대응한다. `파랑 7` 임무를 받았으면 **파랑 7이 들어간
트릭을 내가 이겨야** 한다. 누가 그 카드를 들고 있었는지는 상관없다.

판정은 트릭이 끝난 시점에 한 번에 한다.

- 이긴 사람의 임무에 해당하는 카드가 트릭 안에 있으면 그 임무 완료
- **다른 사람의 임무 카드가 그 트릭에 있으면 즉시 실패**
- 한 트릭에서 여러 임무를 동시에 완료할 수 있다
- 모든 임무가 완료되면 성공
- 트릭을 다 쓰도록 남은 임무가 있으면 실패

## 통신

이 게임의 전부. 손패에 대해 말하는 건 전부 금지라서, 채팅도 막는다
(`noChatInGame: true`).

판당 1회. 카드 한 장을 공개하고 토큰을 세 위치 중 하나에 둔다.

| 위치 | 뜻 |
|---|---|
| 위 | 그 색 중 내 최고 |
| 가운데 | 그 색이 이것뿐 |
| 아래 | 그 색 중 내 최저 |

- 셋 중 하나에 해당해야만 공개할 수 있다 (노랑 2·6·9 에서 6은 불가)
- **로켓은 영구 금지**
- 트릭이 진행 중일 땐 불가. 트릭과 트릭 사이에만
- 한 번 놓은 위치는 나중에 상황이 바뀌어도 못 옮긴다
- 공개한 카드는 손패에 남아 평소대로 내야 한다

## 미션 사다리

`missions.ts` 가 미션 번호를 받아 조건을 돌려준다. 표가 아니라 함수다.

```ts
missionFor(n: number): {
  taskCount: number;          // 임무 개수
  orderMode: 'none' | 'arrow' | 'strict';
  orderedCount: number;       // 순서 토큰이 붙는 임무 수
  commBlockTricks: number;    // 앞 N 트릭 동안 통신 금지
  deadZone: boolean;          // 통신은 되나 위치 표시 없이
  commBanned: boolean;        // 통신 자체 금지
}
```

| 구간 | 대략 |
|---|---|
| 1~5 | 임무 1~2, 제약 없음 |
| 6~15 | 임무 2~3, 화살표 순서 |
| 16~30 | 임무 3~4, 숫자 순서 + 통신 N트릭 차단 |
| 31~45 | 임무 4~5, 데드존 |
| 46~50 | 임무 5+, 통신 전면 금지 |

50을 넘겨도 공식이 계속 돌아가게 둔다 (상한에서 멈추지 않는다).

## 캠페인 진행

한 방에서 연속으로 돈다. 미션 성공 → 결과 화면으로 안 나가고 게임 안에서
`다음 미션`. 실패 → `다시 도전`. `그만하기`를 눌러야 결과 화면으로 간다.

진행도는 방장 브라우저(localStorage)에 저장한다. 다음에 방을 만들면
`이어하기`가 기본이고 `1부터 새로`도 고를 수 있다.

## 네트워크

다빈치 코드와 같은 원칙. 게스트는 의도만 보내고 판정은 호스트가 한다.
sync 는 사람마다 가려서 보낸다 — **내 손패만 숫자, 남의 손패는 장수만**.
공개된 통신 카드는 모두에게 보인다. 호스트 자기 화면도 같은 함수를 통과시킨다.

```
게스트 → 호스트   sc:hello / sc:pickTask / sc:play / sc:comm / sc:next
호스트 → 게스트   sc:sync / sc:end
```

## 엣지 케이스

| 상황 | 처리 |
|---|---|
| 게임 중 이탈 | 협동 게임이라 판이 성립하지 않는다. 남은 인원으로 그 미션을 다시 시작 |
| 2명 이하로 줄어듦 | 결과 화면으로 종료 |
| 재연결 | `sc:hello` 재전송 → 그 사람 몫 sync 재전송 |
| 3인 14번째 카드 | 마지막 트릭 뒤 남는 1장. 쓰지 않고 버린다 |
