# 다빈치 코드 — 설계

2026-11-25

## 무엇

숫자가 적힌 타일을 서로 가리고, 상대 타일의 숫자를 추리해 맞히는 게임.
내 타일이 전부 공개되면 탈락하고, 마지막 한 명이 이긴다.

Hoax Minigames 의 `GameModule` 로 추가한다. 플랫폼 코드는 건드리지 않는다
(`registry.ts` 엔트리 한 줄만 추가).

## 규칙

### 타일

26장.

| 색 | 구성 |
|---|---|
| 검정 | 0~11 + 조커 1장 |
| 흰색 | 0~11 + 조커 1장 |

### 정렬

내 열은 **항상 오름차순**으로 유지된다. 같은 숫자면 **검정이 왼쪽**.
조커는 숫자가 없어서 **아무 위치**에나 넣을 수 있고, 한 번 놓으면 고정이다.

정렬이 강제이기 때문에 "닫힌 타일이 몇 번째에 있는가" 자체가 단서가 된다.
그게 이 게임의 핵심이라, 위치는 숨기지 않는다.

### 시작

- 2인 — 각자 4장
- 3~4인 — 각자 3장

타일이 26장이라 5인 이상은 받지 않는다 (`maxPlayers: 4`).

처음 받은 타일에 조커가 있으면 시작 전에 위치를 고른다.

### 한 턴

```
draw    풀에서 1장 뽑는다 (나만 숫자를 본다)
        └ 조커면 → place
place   내 열의 어느 자리에 넣을지 고른다
guess   상대의 닫힌 타일 하나를 지목하고 숫자(또는 조커)를 말한다
        ├ 맞음 → 그 타일이 모두에게 공개된다 → continue
        └ 틀림 → 내가 뽑은 타일이 공개된 채 내 열에 들어가고 턴 종료
continue  계속 맞힐지 / 멈출지 고른다
        ├ 계속 → guess
        └ 멈춤 → 뽑은 타일이 닫힌 채 내 열에 들어가고 턴 종료
```

뽑은 타일은 **턴이 끝날 때** 정렬 위치에 들어간다. 턴 도중에는 나만 들고 있다.

### 풀이 비었을 때

뽑기를 건너뛰고 바로 `guess`. 틀리면 **내 타일 중 하나를 골라** 공개한다.

### 탈락과 승리

내 타일이 전부 공개되면 탈락. 탈락자는 **관전**으로 남아 끝까지 지켜본다.
닫힌 타일이 남은 사람이 한 명이 되면 그 사람이 승리.

### 방 옵션

| 키 | 라벨 | 선택지 |
|---|---|---|
| `turnLimit` | 제한 시간 | 없음(기본) / 30초 / 60초 |

시간 초과 시 뽑은 타일을 공개하고 턴을 넘긴다.

## 구조

```
src/games/davinci-code/
  rules.ts       덱 생성, 정렬, 추측 판정. 순수 함수 — 네트워크를 모른다
  netSync.ts     메시지 인코딩/디코딩
  index.ts       GameModule. 호스트 authoritative 상태 기계
  render.ts      DOM 렌더
  thumbnail.svg
```

`rules.ts` 가 네트워크를 모르게 분리하는 이유: 판정 로직을 화면이나 연결 없이
그대로 호출해볼 수 있어야 한다. 정렬 자리 계산과 승패 판정이 이 게임에서 제일
틀리기 쉬운 부분이다.

## 네트워크

호스트 authoritative. 게스트는 **의도만** 보내고, 판정과 상태 변경은 호스트가 한다.

```
게스트 → 호스트   dv:hello / dv:place / dv:guess / dv:continue / dv:reveal
호스트 → 게스트   dv:sync / dv:end
```

### sync 는 사람마다 다르게 만든다

이 게임에서 가장 중요한 부분. 호스트는 한 번 만든 상태를 그대로 뿌리면 안 되고,
**받는 사람 기준으로 가려서** 보낸다.

| 대상 | 보내는 것 |
|---|---|
| 내 타일 | 숫자·색 전부 |
| 남의 공개된 타일 | 숫자·색 전부 |
| 남의 닫힌 타일 | **색만**. 숫자는 지운다 |

닫힌 타일의 색을 보내는 이유: 실제 테이블에서도 타일 뒷면 색은 보이고,
색 분포가 추리의 핵심 단서다. 숨기면 게임이 성립하지 않는다.

호스트 자신의 화면도 같은 함수를 통과시킨다. 그래야 호스트만 남의 숫자가
보이는 사고가 구조적으로 안 생긴다.

## 화면

```
┌──────────────────────────────────────────┐
│  영희  ■ ■ □ ■        민수  ■ □ ■        │
│                                          │
│          남은 타일 14장    ⏱ 30          │
│                                          │
│  내 타일   0  3  7  J  9                 │
│  뽑은 타일  5                            │
│  [ 멈추기 ]                              │
└──────────────────────────────────────────┘
```

- 상대의 닫힌 타일은 **색만** 칠한 빈 칸, 공개된 타일은 숫자가 보인다
- 추측: 상대 타일 클릭 → 숫자 패드(0~11, 조커) 팝업 → 선택
- 색은 타일에 이미 보이므로 따로 묻지 않는다
- 내 차례가 아니면 모든 타일이 클릭되지 않는다

## 엣지 케이스

| 상황 | 처리 |
|---|---|
| 게임 중 이탈 | `onPeerLeft` 로 턴 순서에서 뺀다. 그 사람 차례였으면 다음으로 넘긴다 |
| 재연결 | 게스트가 `dv:hello` 재전송 → 호스트가 그 사람 몫 sync 를 다시 보낸다 |
| 시간 초과 | 뽑은 타일 공개 + 턴 종료 |
| 2인에서 1명 이탈 | 남은 1인 승리로 즉시 종료 |
| 풀도 비고 내 타일도 1장 | 틀리면 그 1장이 공개되고 탈락 |

## 분류

`categories: ['보드게임', '추리', '두뇌']`, `maxPlayers: 4`, `minPlayers: 2`.

채팅은 막지 않는다. 블러핑과 떠보기가 재미의 일부다
(`noChatInGame` 을 켜지 않는다).

## 만들지 않는 것

- 조커 위치 재배치 (놓으면 고정)
- 팀전
- 관전자가 모든 숫자를 보는 모드
